# DESIGN SYSTEM & UI SPECIFICATION: "Mów po polsku!" (Polish Poster × Editorial Hybrid)

## 1. Core Aesthetic & Philosophy
- **Concept:** A hybrid of *Polska Szkoła Plakatu* (1960s Polish poster art) and contemporary Polish intellectual editorial design (e.g., *Przekrój*, *Zwykłe Życie*).
- **Anti-Patterns (STRICTLY FORBIDDEN):**
  - NO generic SaaS gradients, glassmorphism, or neon glows.
  - NO rounded "pill" buttons or soft drop shadows (`box-shadow` with blur > 0).
  - NO uniform Bento grids with `border-radius: 16px`.
  - NO childish mascots or gamified streak flames.
- **Tactile Feel:** The interface must feel like printed matter on warm, uncoated cotton paper—combining clean editorial reading space with bold, hand-cut collage accents and ink annotations.

## 2. Color Palette (CSS Variables)

:root {
  --bg-paper: #F4EFE6;          /* Warm uncoated paper base */
  --bg-surface: #EBE4D8;        /* Slightly darker paper for cards/tickets */
  --ink-black: #181818;         /* Primary text, borders, structural lines */
  --ink-muted: #57534E;         /* Secondary captions, metadata */
  --accent-vermilion: #D9381E;  /* Polish poster red (highlights, active states, hand-drawn circles) */
  --accent-cobalt: #1D4ED8;     /* Secondary poster blue (grammatical markers) */
  --accent-ochre: #D97706;      /* Warm mustard/ochre for paper cutouts */
  --border-hairline: rgba(24, 24, 24, 0.25);
}


3. Typography & Polish Diacritics
Font Pairing:

Display / Headings: Bold, slightly condensed grotesque with strong personality and well-crafted Polish diacritics (ą, ć, ę, ł, ń, ó, ś, ź, ż). Recommended: 'Oswald', 'Archivo Black', or 'Syne' (Google Fonts, subset: latin-ext).

Editorial / Reading Text: High-readability literary serif for dialogues, vocabulary definitions, and cultural notes. Recommended: 'Newsreader', 'Lora', or 'Playfair Display' (latin-ext).

Handwritten Annotations / Marginalia: Casual ink script for margin notes. Recommended: 'Caveat' (latin-ext).

Rules:

Headings are uppercase, tight line-height (0.95 to 1.05), tracking -0.02em.

Always test rendering of ą, ę, ł, ż, ź to ensure ogonek tails do not clip.

4. Layout & Grid Architecture
Asymmetric Two-Column Split:

Left Column (55%): Interactive lesson workspace, dialogues, real-world artifacts (receipts, café menus, street signs) combined with bold poster-style cutouts.

Right Column (45%): Editorial dictionary, cultural marginalia, and interactive exercises separated by crisp 1px solid var(--ink-black) vertical dividers.

Geometry:

Strict 0px border-radius on all containers, inputs, and buttons.

Use subtle rotation (transform: rotate(-1.5deg) or 1deg) ONLY on collage elements, photo cutouts, and stamp badges to simulate manual pasting.

5. Component Specifications
Buttons:

Flat background (--bg-paper or --ink-black), 1.5px solid var(--ink-black), 0px border-radius.

Hover state: Hard offset shadow (box-shadow: 4px 4px 0px var(--ink-black); transform: translate(-2px, -2px);) or instant color inversion (--accent-vermilion).

Marginalia & Ink Annotations:

Interactive words in dialogues can be circled with an SVG hand-drawn red ink stroke (--accent-vermilion).

Clicking/hovering reveals a margin note in --ink-muted / --accent-vermilion with a curved SVG arrow pointing to the word.

Progress Tracker ("Bilet Wstępu" / Ticket):

Styled as a perforated tram/museum ticket at the bottom of the screen with notched side edges (radial-gradient cutouts) and a red marker/stamp showing completed modules (ZROBIONE!).

Audio Player:

Minimalist editorial trigger ([ ▶ POSŁUCHAJ ]) paired with an abstract poster-art ear/mouth collage visual rather than a generic waveform bar.
