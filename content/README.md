# Учебный контент

Контент читается сервером при старте. Ошибка формата в любом файле останавливает запуск с указанием файла и строки, поэтому битый урок не попадёт в приложение незаметно.

Каждый новый или изменённый файл проверяет агент `polish-content-reviewer` до коммита.

## Структура

```
content/
  course.yaml          порядок уроков и их группы
  lessons/<slug>.md    один урок
```

### course.yaml

```yaml
groups:
  - id: cases          # латиница, используется в URL и коде
    title: Падежи      # подпись в навигации
    lessons: [mianownik, dopelniacz]
```

Номер урока сквозной по всему курсу и определяется порядком в `course.yaml`. Каждый урок из `lessons/` должен быть упомянут ровно один раз, и наоборот.

## Урок

Файл начинается с front-matter, дальше идут разделы `##`. Текста до первого раздела нет: вступление — это `summary`.

```markdown
---
slug: dopelniacz                       # совпадает с именем файла
title: Dopełniacz                      # заголовок урока
subtitle: "Родительный: kogo? czego?"  # строка в списках и ссылках на соседние уроки
summary: Отвечает на вопросы **kogo? czego?** …
minutes: 12                            # оценка времени чтения
---

## Когда нужен

…
```

Разделы нумеруются автоматически (01, 02, …) и попадают в план урока.

### Разметка внутри текста

| Запись | Значение |
|---|---|
| `**слово**` | жирный |
| `*слово*` | курсив — польские примеры внутри русского текста |
| `czas{u}` | окончание (выделяется кобальтом) |

`{…}` работает везде: в абзацах, таблицах, блоках ниже.

### Блоки

Обычный абзац, маркированный список и таблица (GFM) пишутся как в Markdown.

**Пометка** — абзац, начинающийся с `↳ `. Выводится приглушённо, относится к своему разделу.

```markdown
↳ После k и g вместо -y пишется -i: *noga → nogi*.
```

**Примеры** — подпись, польская фраза, перевод через ` | `:

````markdown
```examples
Отрицание | Nie mam czas{u}. | У меня нет времени.
```
````

**Диалог** — реплика и перевод через ` | `. Необязательный `caption="…"` — подпись над диалогом: что он показывает. Строка `↑ …` — рукописная пометка к предыдущей реплике. Пишется рукописным шрифтом, поэтому польских слов и окончаний в ней нет.

````markdown
```dialogue
Nie ma już chleb{a}? | Хлеба уже нет?
↑ то самое «часто», см. таблицу окончаний
```
````

**Карточка** — короткий список на «бумажке» (список покупок, меню). Ставится перед блоком, рядом с которым её показать. `title` — заголовок на самой карточке, необязательный `caption` — подпись над ней. Если карточка стоит рядом с диалогом, подписи обоих называют то, что сравнивается (например, падежи).

````markdown
```card title="Lista zakupów" caption="Список · именительный"
woda
ser
```
````

Любая другая разметка (заголовки других уровней, картинки, HTML, цитаты, неизвестные блоки) — ошибка.
